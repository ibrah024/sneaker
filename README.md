# SoleStreet — Sneaker Selling Store

College Term Work 1 (TW–1) — Full Stack Web Development.

## Features
- Responsive landing page
- Product display with search and category filtering
- Add to cart with quantity controls
- Shopping cart using browser localStorage
- Payment page with JavaScript form validation
- Navigation between all pages
- No external libraries required

## Technologies
HTML5, CSS3 and JavaScript (ES6).

## How to run
Open `index.html` in a browser. For best results, use VS Code with the Live Server extension.

## GitHub
Create a repository named `sneaker-store`, upload all project files, and submit the repository URL.

## Academic integrity
This project is intended as a TW–1 educational submission. Understand the HTML, CSS and JavaScript before presenting or explaining the project.
